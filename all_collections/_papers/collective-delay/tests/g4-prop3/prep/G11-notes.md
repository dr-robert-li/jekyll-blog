# G11 private notes (preparer only)

Case: Dutch childcare-benefits scandal (toeslagenaffaire); Belastingdienst/Toeslagen risicoclassificatiemodel.

## Adoption
A+0 = 2013 (model used monthly from April 2013 to November 2019 for selection; definitively stopped July 2020; per S1). Conversions: 2014=A+1, 2017=A+4, 2019=A+6, 2020=A+7, 2021=A+8, 2022=A+9, 2023=A+10, 2024=A+11, 2025=A+12. E1 window starts 2010 = A-3 (district-court data cover 2010-2019).
Packet uses "risk-scoring model" instead of the official name to respect the banned "class" substring.

## Judgement calls / gaps
- AP 2020 report + 2021 fine treated as one regulatory proceeding (E6). FSV fine (E16) included as a separate proceeding on a related practice of the same operator. Whether the FSV fine was contested: not found.
- Criminal track: OM decision (Jan 2021) and art. 12 complaint counted once at the highest decided level (E19, Hof 2022). Complaint against officials (E23) is a separate proceeding. Ministers' complaint (E11) separate; no government/Kamer order to prosecute was found.
- Packet says the finance minister did not contest the 2.75m fine: reported that State Secretary Van Huffelen called it very painful and would not object (S9).
- ADR figures (1,300 / 3,700) taken from S15's citation of the ADR report, not read in the ADR report itself.
- KPMG external re-assessment of CAF cases (referenced in search results) and a KPMG review of CAF-team outputs (letter 2024) exist but date/findings not verified -> not included as episodes. Possible additional episodes to check: Kinderombudsman reports, College voor de Rechten van de Mens opinions, civil damages suits against the State.
- Statement in context that the ABRvS followed the all-or-nothing line from 2011 to Oct 2019: S5.
- E1 period starts before adoption (2010) because the courts' statistics cover 2010-2019.
